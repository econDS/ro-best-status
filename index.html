ใช้ Base Stat + โบนัสในสูตร และหาค่าสูตรดิบสูงสุดในงบ ไม่ได้อ้างว่าเป็นอัตราสำเร็จจริงที่ตรวจยืนยันกับเซิร์ฟเวอร์ ไม่มีการเติมเพดานสำเร็จหรือกฎปัดเศษที่แหล่งอ้างอิงไม่ได้ระบุ ตัวเลขจึงอาจต่ำกว่า 0% หรือสูงกว่า 100% ส่วนแถบภาพจำกัดไว้ที่ 0–100% เพื่อการแสดงผลเท่านั้น

เมื่อค่าจากสูตรดิบเท่ากัน ระบบเลือกชุดที่ใช้แต้มน้อยกว่า ทั้งสองปลายช่วงปรุงยาใช้สเตตัสแนะนำชุดเดียวกัน เพราะ Potion_Rate ไม่เปลี่ยนน้ำหนักของสเตตัส

ตารางต้นทุนและงบสเตตัสยังอ้างอิง RO-help-tool · commit 1cc20f4 ↗ แยกจากสูตรสำเร็จของ iRO Wiki โปรไฟล์ Class 2 รองรับเลเวล 1–99 และเพดาน 99 ส่วน Class 3 รองรับเลเวล 99–200 และเพดาน 130 ตามต้นทาง ไม่ใช่การรับรองเพดานของ iRO เวอร์ชันปัจจุบัน
